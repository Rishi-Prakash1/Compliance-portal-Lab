# Information Security Policy - OT Environment  (Doc ID: ISP-OT-001, v3.0, Approved 2026-02-10)

- The Plant Unit 2 DCS/SCADA is notified as a Protected System under Section 70 of the IT Act, 2000.
- A Chief Information Security Officer (CISO) is appointed and accountable for the Protected System.
- Access to the Protected System is limited to authorised personnel listed in the access register.
- An information security audit of the Protected System is performed annually by a CERT-In empanelled auditor.
- Security architecture follows IEC 62443-3-2 zone and conduit design (see ARCH-OT-002).
